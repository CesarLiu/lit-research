Question: How is controllability achieved in driving scenario generation models?

Controllability is obtained by conditioning generation on signals a user can set, and the models differ in where that signal enters. One route conditions on the reward or return. CtRL-Sim tilts the learned return distribution exponentially with one coefficient per reward dimension: negative values give worse-than-average behaviour, positive values better-than-average, and the measured metrics change relatively monotonically with the coefficient (pqac-e7c06534). Fine-tuning on a small set of collision scenarios strengthens the adversarial end of this control (pqac-e7c06534).

A second route conditions a diffusion model on explicit scene attributes. Scenario Diffusion concatenates an encoded bird's-eye-view map with the noisy sample, and feeds per-agent tokens (position, speed, length, motion profile) through cross-attention; a global scene token tied to the token-mask probability sets how many agents are generated (pqac-f3659242). DragTraffic conditions a diffusion refinement stage, after a regression model supplies an initial trajectory, on a context of vehicle type, size, and start and target position, speed and orientation, which the user sets by dragging or typing (pqac-abc1357f, pqac-bea94318).

A third route builds control into the latent space. A guided variational autoencoder reserves one latent dimension for the scenario class, uses a class-conditional prior with an alignment loss, and avoids external conditioning that the authors argue can distort the probability distribution needed for failure-probability estimation (pqac-8151e453).
